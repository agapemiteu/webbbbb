# Webb project instructions

Read [START_HERE.md](START_HERE.md) for local access and [docs/SESSION_HANDOFF.md](docs/SESSION_HANDOFF.md) before changing the project. The handoff records the implementation, live URLs, checks, and remaining work.

Webb is a Chrome browser agent for the AssemblyAI voice agent hackathon. Preserve the frozen positioning in the user handoff: "Talk to the web" and "Make the web executable." The hero flow follows speech from a tutorial tab, maps it to the current target page, accepts direct user corrections, verifies actions, and requires direct user confirmation for consequential actions.

Do not add an AI collaborator, author, or credit to the repository. Keep code and copy direct. Do not use em dashes. Do not fork Aalto. Keep AssemblyAI and Groq keys on the Worker, never in the extension or site.

Before claiming a live voice demo, verify the unpacked extension in Chrome with real AssemblyAI transcription, Groq planning, and a configured Cloudflare Worker. The public site and demo pages alone do not prove that loop.
